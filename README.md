# FLOYZTE — CS2 Community website

Адаптивный одностраничный сайт игрового сообщества FLOYZTE.

## Файлы
- `index.html` — структура страницы
- `styles.css` — оформление и адаптивность
- `app.js` — мобильное меню и уведомления
- `assets/logo.svg` — логотип

## Публикация
Проект можно бесплатно опубликовать через Cloudflare Pages: подключить этот GitHub-репозиторий, выбрать **Direct Upload** или Git integration. Для статического сайта сборка не нужна; корневая директория — `/`.

## Перед запуском
- Замени временную ссылку Discord в `index.html` на приглашение своего сообщества.
- Добавь реальные IP/порты серверов после их аренды и настройки.
- Сейчас игровые серверы не развернуты, карточки режимов имеют статус «Скоро».
